# Spooky Quiz submission form

Form ID: KpzeqK. Reuse this form; do not create another.

Guest flow: guest name, question text, optional image, answer, submit, then a link to submit another question.

Ask guests to contribute at least two and no more than five overall. These are instructions rather than an enforced per-person limit. There is no count selector, email field, guest sign-in or quiz-type selector.

Fields: name, question and answer are required. Image is optional, one file up to 10 MB. Accept any quiz format through long text. The answer can include a source, explanation or scoring instructions.

The thank-you page links to https://tally.so/r/KpzeqK for the next contribution. Tally opens that link in a new tab.

Publish edits to this same form to update the website embed. Close the actual form when submissions finish, not just the website.
